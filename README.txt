Terminal 6S v1.1.0

Nowosci:
- kolejka zapisow offline w localStorage,
- automatyczna synchronizacja po odzyskaniu internetu,
- licznik wpisow oczekujacych,
- blokada przyciskow podczas zapisu,
- numer wersji aplikacji,
- automatyczne pobieranie nowej wersji PWA,
- przycisk Zainstaluj ukryty w zainstalowanej aplikacji.

Wgraj na GitHub Pages wszystkie pliki, zachowujac folder icons. Zastap stary index.html, statystyki_6S.html, sw.js i manifest.webmanifest.

Po wdrozeniu otworz strone raz online i odswiez. Wpisy wykonane offline zostana wyslane automatycznie po powrocie internetu. Bledy uprawnien lub walidacji pozostana w kolejce, dopoki przyczyna nie zostanie usunieta.
