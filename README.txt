Terminal 6S v1.2.0

Nowa funkcja: trwałe przypisanie operatora do urządzenia.

Pierwsze uruchomienie:
1. Operator wybiera siebie z listy.
2. Klika Przypisz operatora do urządzenia.
3. Potwierdza wybór.

Po przypisaniu:
- operator pozostaje wybrany po zamknięciu i ponownym uruchomieniu aplikacji,
- lista operatorów jest zablokowana,
- przycisk Zmień operatora jest ukryty,
- historia jest automatycznie ograniczona do przypisanego operatora,
- zmiana operatora jest możliwa dopiero po wyczyszczeniu danych aplikacji lub danych witryny.
